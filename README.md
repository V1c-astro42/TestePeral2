# Título
CÁLCULO DE MÉDIA DE ALUNOS
***
# Descrição
Projeto simples para realizar a média das notas dos alunos
***
# Tecnologias
Linguegem utilizada: python
***
# Como Instalar e executar 
Utilizar VScode, baixar o arquivo e executar no VScode com o Python baixado
***
# Exemplo de uso
Ao informar as notas do aluno, o sistema irá realizar a soma delas e divid-las por 2. Como este exemplo:
```Primeira nota: 10  segunda nota: 8  conta: (10+8)/2= 9  Média= 9```
